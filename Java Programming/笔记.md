## 基本数据类型

| 类型 | 位数 | 取值范围或含义 |
| --- | --- | --- |
| `byte` | 8 | −128～127 |
| `short` | 16 | −32,768～32,767 |
| `int` | 32 | −2,147,483,648～2,147,483,647 |
| `long` | 64 | −2⁶³～2⁶³−1 |
| `float` | 32 | IEEE 754 单精度；最大有限绝对值约 3.4 × 10³⁸，最小正非零值约 1.4 × 10⁻⁴⁵ |
| `double` | 64 | IEEE 754 双精度；最大有限绝对值约 1.8 × 10³⁰⁸，最小正非零值约 4.9 × 10⁻³²⁴ |
| `char` | 16 | 无符号 UTF-16 代码单元，0～65,535 |
| `boolean` | — | `true` 或 `false`，语言规范不规定其存储字节数 |

浮点类型也可以表示负数、正负零、无穷大和 `NaN`。

### 说明

- e+38表示是乘以10的38次方，同样，e-45表示乘以10的负45次方。

- 在java中整数默认是int类型，浮点数默认是double类型。

### 需要记忆以下几点

- **`byte` 类型的取值范围：** −128～127。
- **`int` 类型的大概取值范围：** −21 亿多～21 亿多。
- **按可表示数值的最大量级比较：** `double > float > long > int > short > byte`。
- **范围与精度：** 范围更大不代表整数精度更高；`float` 不能精确表示所有 `int`，`double` 也不能精确表示所有 `long`。

```java
public class VariableDemo3{
    public static void main(String[] args){
        //1.定义byte类型的变量
        //数据类型 变量名 = 数据值;
        byte a = 10;
        System.out.println(a);
        //2.定义short类型的变量
        short b = 20;
        System.out.println(b);
        //3.定义int类型的变量
        int c = 30;
        System.out.println(c);
        //4.定义long类型的变量
        long d = 123456789123456789L;
        System.out.println(d);
        //5.定义float类型的变量
        float e = 10.1F;
        System.out.println(e);
        //6.定义double类型的变量
        double f = 20.3;
        System.out.println(f);
        //7.定义char类型的变量
        char g = 'a';
        System.out.println(g);
        //8.定义boolean类型的变量
        boolean h = true;
        System.out.println(h);
        //9.定义String类型的变量
        String name = "黑马谢广坤";
        System.out.println(name);
    }

```

**注意点**

- 如果要定义 一个整数类型的变量，不知道选择哪种数据类型了，默认使用int。

- 如果要定义 一个小数类型的变量，不知道选择哪种数据类型了，默认使用double。

- 整数文字超出 `int` 范围时，需要加 `L` 后缀才表示 `long`（大小写都可以，建议大写）。例如 `long n = 10;` 也合法，`10` 会由 `int` 转为 `long`。

- 如果要定义一个float类型的变量，那么在数据值的后面需要加上F后缀。（大小写都可以）

### 键盘录入涉及到的方法如下：

- **读取字符串：** `next()`、`nextLine()`。
- **读取数值：** `nextInt()`、`nextDouble()`。

#### 1）next（）、nextLine（）：

可以接受任意数据，但是都会返回一个字符串。

**代码示例**

```java
Scanner sc = new Scanner(System.in);
String s = sc.next();//录入的所有数据都会看做是字符串
System.out.println(s);
```

**代码示例**

```java
Scanner sc = new Scanner(System.in);
String s = sc.nextLine();//录入的所有数据都会看做是字符串
System.out.println(s);
```

#### 2）nextInt（）：

- **可接受内容：** 只能接受整数。例如，键盘录入 123，会把 123 当作 `int` 类型的整数返回。
- **输入错误：** 录入小数或者其他字母会报错。

**代码示例**

```java
Scanner sc = new Scanner(System.in);
int s = sc.nextInt();//只能录入整数
System.out.println(s);
```

#### 3）nextDouble（）：

- **可接受内容：** 能接收整数和小数，都会看作小数返回。
- **输入错误：** 录入字母会报错。

**代码示例**

```java
Scanner sc = new Scanner(System.in);
double d = sc.nextDouble();//录入的整数，小数都会看做小数。
//录入字母会报错
System.out.println(d);
```

### 第一个细节：

- **停止位置：** `next()`、`nextInt()`、`nextDouble()` 接收数据时，遇到空格、回车、制表符中的一个就会停止接收数据。
- **剩余输入：** 分隔符以及后面的数据仍可能留在输入中；如果后面还有其他键盘录入方法，会继续接收这些数据。

**代码示例**

```java
Scanner sc = new Scanner(System.in);
String s1 = sc.next();
String s2 = sc.next();
System.out.println(s1);
System.out.println(s2);
//此时值键盘录入一次a b(注意a和b之间用空格隔开)
//那么第一个next();会接收a，a后面是空格，那么就停止，所以打印s1是a
//但是空格+b还在内存中。
//第二个next会去掉前面的空格，只接收b
//所以第二个s2打印出来是b
```

### 第二个细节：

nextLine（）方法是把一整行全部接收完毕。

**代码示例**

```java
Scanner sc = new Scanner(System.in);
String s = sc.nextLine();
System.out.println(s);
//键盘录入a b(注意a和b之间用空格隔开)
//那么nextLine不会过滤前面和后面的空格，会把这一整行数据全部接收完毕。
```

## 如何配合使用输入方法

`next()`、`nextInt()`、`nextDouble()` 按 token 读取；`nextLine()` 读取当前位置到本行结束的内容，并消费行结束符。

它们可以混用，但 `nextInt()` 等方法后可能留下换行符，紧接着的 `nextLine()` 会先读到当前行剩余的内容（常常是空字符串）。若要读取下一整行，先消费当前行的剩余内容：

```java
Scanner sc = new Scanner(System.in);
int age = sc.nextInt();
sc.nextLine(); // 消费本行剩余内容及换行符
String name = sc.nextLine();
```

也可以统一用 `nextLine()`，需要整数时再用 `Integer.parseInt()` 转换。

按 token 读取的示例：

```java
Scanner sc = new Scanner(System.in);
String s = sc.next(); // 键盘录入123
System.out.println("此时为字符串：" + s);
int i = sc.nextInt(); // 再录入123
System.out.println("此时为整数：" + i);
```

按行读取并转换的独立示例：

```java
Scanner sc = new Scanner(System.in);
String s = sc.nextLine(); // 键盘录入123
System.out.println("此时为字符串：" + s);
int i = Integer.parseInt(s);
System.out.println("此时为整数：" + i);
```

## 两种自动类型提升规则：

- 取值范围小的，和取值范围大的进行运算，小的会先提升为大的，再进行运算。

- byte、short、char三种类型的数据在运算的时候，都会直接先提升为int，然后再进行运算。

## 常见的数值拓宽转换方向

`byte → short → int → long → float → double` 是常见的数值拓宽转换方向，`char → int` 也可以。拓宽转换也可能损失精度，例如 `int → float`。

## 强制类型转换

### 概念：

如果要把一个取值范围大的数据或者变量赋值给另一个取值范围小的变量。是不允许直接操作。

如果一定要这么干，就需要加入强制转换。

### 书写格式：

目标数据类型 变量名 = （目标数据类型）被强转的数据；

**简单理解**

要转成什么类型的，那么就在小括号中写什么类型就可以了。

**案例**

```java
public class OperatorDemo2 {
    public static void main(String[] args) {
        double a = 12.3;
        int b = (int) a;
        System.out.println(b);//12
    }
}
```

**注意点**

强制转换有可能会导致数据发生错误。（数据的精度丢失）

## 字符的+操作

### 规则：

`char` 参与数值加法时，会提升为其 UTF-16 代码单元对应的 `int` 值再计算。英文字母等 ASCII 字符的码值与此一致；如果另一侧是字符串，则进行字符串拼接。

### 案例：

```java
char c = 'a';
int result = c + 0;
System.out.println(result);//97
```

ASCII码表中：

- **`'a'`：** 97。
- **`'A'`：** 65。

## 扩展赋值运算符注意点：

扩展的赋值运算符中隐层还包含了一个强制转换。

以+=为例。

当 `a` 的类型为 `byte` 时，`a += b` 的数值转换效果相当于 `a = (byte) (a + b)`。一般情况下，复合赋值会把结果转换为左侧变量的类型，并且左侧只求值一次。

```java
public class OperatorDemo8 {
    public static void main(String[] args) {
        byte a = 10;
        byte b = 20;
        //a += b;
        a = (byte)(a + b);
        System.out.println(a);//30
    }
}
```

## 短路逻辑运算符

分类： && ||

### &&：

对布尔值的真值规则与 `&` 相同，但具有短路效果。

### ||：

对布尔值的真值规则与 `|` 相同，但具有短路效果。

### 逻辑核心：

- 当左边不能确定整个表达式的结果，右边才会执行。

- 当左边能确定整个表达式的结果，那么右边就不会执行了。从而提高了代码的运行效率。

### 总结：

`&&` 与 `&`、`||` 与 `|` 对布尔值具有相同的真值表，但右侧表达式是否执行不同；如果右侧有副作用或可能抛出异常，程序行为就可能不同。

### 建议：

最为常用： && || ！

## 三元运算符

又叫做：三元表达式或者问号冒号表达式。

### 格式：

关系表达式 ？ 表达式1 ：表达式2 ；

### 计算规则：

1. **计算条件：** 计算关系表达式的值。
2. **选择结果：** 如果值为真，执行表达式 1；如果值为假，执行表达式 2。

### 注意点：

三元运算符的最终结果一定要被使用，要么赋值给一个变量，要么直接打印出来。

### 案例：

```java
System.out.println(a > b ? a : b);
```

### 数组作为参数（下面的 `getMax` 要求数组非空）

```java
public class MethodTest {
    public static void main(String[] args) {
        //定义一个数组，用静态初始化完成数组元素初始化
        int[] arr = {12, 45, 98, 73, 60};
        int number = getMax(arr);
        System.out.println("number:" + number);
    }
    public static int getMax(int[] arr) {
        int max = arr[0];
        for(int x=1; x<arr.length; x++) {
            if(arr[x] > max) {
                max = arr[x];
            }
        }
        return max;
    }
}
```

## 小结

1. `static` 修饰的字段和方法分别称为静态变量、静态方法。对于同一个已加载的类，静态变量由各实例共享；读写仍受访问权限及 `final` 等规则限制。推荐通过类名访问。
2. 无 `static` 修饰的字段和方法分别称为实例变量、实例方法，通常通过对象引用访问。
3. 静态成员与类关联，其初始化遵循类初始化规则；不宜把它们概括为一定存储在某块固定的“静态区”。
4. 每个对象有自己的实例字段；实例方法操作调用它的对象，并不是每创建一个对象就复制一份方法代码。

## 子类不能继承的内容

| 内容 | 是否继承 |

## 继承后的特点—成员方法

### case1：成员方法不重名

如果子类父类中出现不重名的成员方法，这时的调用是没有影响的。对象调用方法时，会先在子类中查找有没有对应的方法，若子类中存在就会执行子类中的方法，若子类中不存在就会执行父类中相应的方法。

### case2：成员方法重名

如果子类提供了对父类实例方法的重写，通过子类对象调用时会执行子类的实现。仅方法名相同还不够：参数列表不同可能构成重载。

- **访问权限：** 不能缩小。
- **特殊情况：** `private` 方法不被重写，`static` 方法发生的是隐藏。

```java
        admin.setName("管理员");
        admin.setAge(35);
        register(s);
        register(t);
        register(admin);
    }
    //这个方法既能接收老师，又能接收学生，还能接收管理员
    //这里把参数写成三个类型共同的父类Person

        p.show();
```

### 抽象类的使用

要求：继承抽象类的子类必须重写父类所有的抽象方法。否则，该子类也必须声明为抽象类。

此时的方法重写，是子类对父类抽象方法的完成实现，我们将这种方法重写的操作，也叫做实现方法。

代码举例：

```java
// 父类：抽象类
abstract class Employee {
    private String id;
    private String name;
    private double salary;

    public Employee() {}

    public Employee(String id, String name, double salary) {
        this.id = id;
        this.name = name;
        this.salary = salary;
    }

    // 类中的抽象方法必须放在抽象类中
    public abstract void work();
}
```

```java
// 定义一个子类继承抽象类
class Manager extends Employee {
    public Manager() {
    }
    public Manager(String id, String name, double salary) {
        super(id, name, salary);
    }
    // 2.重写父类的抽象方法
    @Override
    public void work() {
        System.out.println("管理其他人");
    }
}
```

```java
// 定义一个子类继承抽象类
class Cook extends Employee {
    public Cook() {
    }
    public Cook(String id, String name, double salary) {
        super(id, name, salary);
    }
    @Override
    public void work() {
        System.out.println("厨师炒菜多加点盐...");
    }
}
```

```java
// 测试类
public class Demo10 {

        // 假设抽象类让我们创建对象,里面的抽象方法没有方法体,无法执行.所以不让我们创建对象
        // Employee e = new Employee();
        // e.work();
```

### 抽象类的细节

- 抽象类不能创建对象，如果创建，编译无法通过而报错。只能创建其非抽象子类的对象。

- 抽象类中，可以有构造方法，是供子类创建对象时，初始化父类成员使用的。

- 抽象类中，不一定包含抽象方法，但是有抽象方法的类必定是抽象类。

- 抽象类的子类，必须重写抽象父类中所有的抽象方法，否则子类也必须定义成抽象类，编译无法通过而报错。

- 抽象类存在的意义是为了被子类继承。

## 接口

接口体现一种规范。非抽象的实现类必须提供接口所要求的全部抽象方法的实现（也可以继承已有的有效实现）；否则该类必须声明为抽象类。接口的 `default` 和 `static` 方法不要求实现类逐一重写。

### 接口与接口的多继承

接口与接口之间是可以多继承的：也就是一个接口可以同时继承多个接口,接口继承接口就是把其他接口的抽象方法与本接口进行了合并。

![课程插图](assets/typed/p056-03.png)

### 接口的细节

1. 当两个接口中存在相同抽象方法的时候，该怎么办？

   若两个方法的签名相同、返回类型等要求兼容，实现一次即可同时满足两个接口；方法必须满足接口要求的 `public` 访问权限。若返回类型冲突，则不能简单用一个实现解决。

2. 实现类能不能继承A类的时候，同时实现其他接口呢？

   继承的父类，就好比是亲爸爸一样 实现的接口，就好比是干爹一样 可以继承一个类的同时，再实现多个接口，只不过，要把接口里面所有的抽象方法，全部实现。

3. 实现类能不能继承一个抽象类的时候，同时实现其他接口呢？

   实现类可以继承一个抽象类的同时，再实现其他多个接口，只不过要把里面所有的抽象方法全部重写。

4. 实现类 Zi 实现一个接口，同时继承 Fu 类。如果接口和父类都有相同签名的方法，子类如何处理？

   如果继承的父类方法是 `public`，且签名、返回类型等满足接口要求，并能满足业务需求，子类可以直接继承该实现；否则需要在子类中提供符合接口要求的重写实现。

5. 如果接口有 10 个抽象方法，而实现类只关心其中一个，该怎么办？

   可以在接口和实现类之间新建一个中间类（适配器类），让它实现接口，并为各方法提供默认实现。`void` 方法可以使用空方法体；有返回值的方法必须返回符合约定的值。子类继承适配器类，只重写自己关心的方法。通常把适配器类声明为抽象类，避免直接创建无实际用途的适配器对象。
