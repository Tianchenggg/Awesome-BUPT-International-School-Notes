# Awesome BUPT International School Notes

北京邮电大学国际学院课程笔记，收录课程笔记、复习提纲、例题和题目整理，供学习与期末复习参考。

按课程分文件夹，正文统一使用 Markdown，保留笔记中原有的中英文表达。公式可直接在 GitHub 阅读，配图放在各课程的 `assets` 文件夹中。

如果这些笔记对你有帮助，希望可以给这个仓库一个 **Star ⭐**！

## 学课程的原则

1. 最后几节课重点听，老师会讲重点。
2. 把所有往年题写完，按知识点整理，全部背掉。
3. 看 PPT 基本没用。

## 阅读方式

点击上方课程名即可打开对应的笔记。也可以下载整个仓库，用支持 Markdown 数学公式与 Mermaid 的编辑器阅读。
