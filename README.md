这里整理了北京邮电大学国际学院的课程笔记、复习提纲、例题和题目，供日常学习与期末复习使用。每门课程独立成一个文件夹，正文统一使用 Markdown，保留笔记中原有的中英文表达。

如果这些笔记对你有帮助，希望可以给这个仓库一个 **Star ⭐**！

## 在线学习

配套的 **BUPT Study** 学习网站收录 **17 门课程、199 个章节与 1,903 道自测题**，课程采用每行一门的列表布局，可直接进入笔记与自测，并显示阅读进度。支持站内阅读与复习。题目来自笔记中的独立问答、加粗考点和例题，附对应参考答案；重复知识点合并整理。

[![BUPT Study 学习网站界面](assets/readme/website.png)](https://bupt-study-notes.htcafasfadf.chatgpt.site)

| 模式 | 使用方式 |
| :--- | :--- |
| **站内阅读** | 按课程与章节浏览笔记，直接查看公式、表格、插图与 Mermaid 图示。 |
| **自测练习** | 答案默认隐藏，先独立作答，再逐题展开核对；支持按章节练习、自评、待复习筛选与打乱顺序。 |
| **本地复习进度** | 阅读进度、作答草稿和掌握情况保存在当前浏览器，无需注册登录。 |

网站源码与本地运行说明见 [`website`](website/README.md)。

## 使用方式

- **在线学习**：打开 [BUPT Study](https://bupt-study-notes.htcafasfadf.chatgpt.site)，在站内阅读完整笔记并进行自测。
- **GitHub 阅读**：从上方课程目录进入，可直接查看数学公式和 Mermaid 图表。
- **本地阅读**：通过仓库的 **Code → Download ZIP** 下载全部内容，使用支持 Markdown 数学公式与 Mermaid 的编辑器打开。
- **查找配图**：每门课程的图片保存在该课程的 `assets` 文件夹中；下载时保留目录结构即可。

## 学课程的原则

1. 最后几节课重点听，老师会讲重点。
2. 把所有往年题写完，按知识点整理，全部背掉。
3. 看ppt基本没用
